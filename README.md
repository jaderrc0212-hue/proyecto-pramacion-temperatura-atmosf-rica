# Proyecto: Análisis de Temperaturas Atmosféricas de Chile 🇨🇱

## 📖 Descripción
Este proyecto procesa y analiza datos históricos de temperaturas atmosféricas en Chile para identificar patrones climáticos mediante Python.

## 📂 Origen de los Datos
Los datos fueron obtenidos del repositorio público de **bastianolea** (Temperaturas Chile)[cite: 11].

* **Dataset:** `dataset.csv` (ubicado en la carpeta `datos/`)[cite: 12].

## 🛠️ Estructura del Proyecto
- `datos/`: Contiene el conjunto de datos de temperaturas[cite: 12].
- `src/`: Módulos de código Python (`carga.py`, etc.)[cite: 12].
- `reportes/`: Archivos y resultados generados por el análisis[cite: 12].
- `main.py`: Script principal para ejecutar el programa[cite: 12].
